# Improved Unsupervised Clustering — Design Spec

**Date:** 2026-09-12
**Notebook:** `notebooks/11_improved_clustering.ipynb`

---

## Goal

Run three targeted improvement experiments on top of the existing unsupervised
clustering baseline (notebook 02) and feed 8 new methods into the comparison
table — without modifying any existing notebook or result.

---

## Background

Notebook 02 established the baseline: KMeans/Agglomerative/DEC × MiniLM/RoBERTa
on BART-generated article summaries, all with k=16. Best result: MiniLM
Agglomerative at ~45% ACC. Three known weaknesses:
1. MiniLM (`all-MiniLM-L6-v2`) is the fastest, not the strongest, sentence
   transformer.
2. UMAP hyperparameters use library defaults; no tuning was done.
3. BART summaries may blur category-discriminative signals that raw titles
   preserve.

---

## Experiments

### Experiment A — MPNet embeddings

Replace MiniLM with `all-mpnet-base-v2` (768-dim), a stronger sentence
transformer trained on more data. Embed the same BART summaries used in
notebook 02 (column `summary` of `train_clean.parquet`). Run all three
clustering algorithms with the same UMAP defaults as notebook 02.

**New methods:** `mpnet_kmeans`, `mpnet_agglomerative`, `mpnet_dec`

**Embedding cache file:** `embeddings_cache/mpnet_train_full_summary.npy`

### Experiment B — UMAP hyperparameter tuning

Keep MiniLM embeddings (already cached). Run a 3×3 grid search over:
- `n_neighbors`: [15, 30, 50]
- `min_dist`: [0.0, 0.05, 0.1]
- `n_components`: fixed at 50 (same as baseline)
- `metric`: fixed at "cosine" (same as baseline)
- `random_state`: fixed at 42

Score each of the 9 combinations by mean **silhouette score** after KMeans
(n_clusters=16, n_init=10, random_state=42). Pick the combination with the
highest silhouette. Run KMeans and Agglomerative with those best params.

DEC is excluded from this experiment: DEC has its own learned dimensionality
reduction (autoencoder) and does not use UMAP.

**New methods:** `minilm_kmeans_umap`, `minilm_agglomerative_umap`

**Best params** are printed and stored in a markdown cell comment for
reproducibility; they are not saved to a file (the notebook cell output is
the record).

### Experiment C — Title embeddings

Embed the article **title** column (`train_clean.parquet['title']`, avg 72
chars) with MiniLM (`all-MiniLM-L6-v2`) instead of the BART summary. Run all
three clustering algorithms with the same UMAP defaults as notebook 02.

**New methods:** `title_minilm_kmeans`, `title_minilm_agglomerative`,
`title_minilm_dec`

**Embedding cache file:** `embeddings_cache/minilm_train_title.npy`

## Notebook Structure

### Cell 1 — Markdown: description and experiment overview

### Cell 2 — Imports, config, data loading

```python
METHODS_MPNET  = ["mpnet_kmeans", "mpnet_agglomerative", "mpnet_dec"]
METHODS_UMAP   = ["minilm_kmeans_umap", "minilm_agglomerative_umap"]
METHODS_TITLE  = ["title_minilm_kmeans", "title_minilm_agglomerative",
                  "title_minilm_dec"]
N_CLUSTERS     = 16
UMAP_DIM       = 50
SEED           = 42
SILHOUETTE_SAMPLE_SIZE = 2000   # from config
```

Load `train_clean.parquet`. Extract `true_labels`, `summaries`, `titles`.

### Cell 3 — Helper: `umap_reduce()` and `run_and_save()`

Copy the same `umap_reduce(embeddings, n_components, n_neighbors, min_dist,
metric, seed)` helper used in notebook 02. Copy the same `run_and_save(name,
cluster_labels, emb_original)` helper — identical signature and artifact
schema.

### Experiment A cells (cells 4–6)

- Cell 4: Embed summaries with `all-mpnet-base-v2`; cache to
  `embeddings_cache/mpnet_train_full_summary.npy`; skip if file exists.
  Print shape — must be (3824, 768).
- Cell 5: UMAP-reduce MPNet embeddings (default params: n_neighbors=15,
  min_dist=0.1, n_components=50, metric="cosine"). Run KMeans and
  Agglomerative. Call `run_and_save()` for each.
- Cell 6: Run DEC on raw MPNet embeddings (no UMAP — same as notebook 02).
  Call `run_and_save()`.

### Experiment B cells (cells 7–8)

- Cell 7: Load cached MiniLM embeddings. Run 3×3 grid (n_neighbors ×
  min_dist). For each combo: UMAP-reduce → KMeans(16) → silhouette score.
  Print grid table. Identify best combo. Print winning params.
- Cell 8: UMAP-reduce with best params. Run KMeans and Agglomerative. Call
  `run_and_save()` for `minilm_kmeans_umap` and
  `minilm_agglomerative_umap`.

### Experiment C cells (cells 9–11)

- Cell 9: Embed titles with `all-MiniLM-L6-v2`; cache to
  `embeddings_cache/minilm_train_title.npy`; skip if file exists.
  Print shape — must be (3824, 384).
- Cell 10: UMAP-reduce title embeddings (default params). Run KMeans and
  Agglomerative. Call `run_and_save()`.
- Cell 11: Run DEC on raw title embeddings. Call `run_and_save()`.

### Cell 12 — Results summary table

Print all 8 methods side by side: ACC, ARI, NMI, silhouette, separation
ratio. Compare against baseline (notebook 02 best: minilm_agglomerative
ACC=0.4506).

## Global Constraints

- Python ≥ 3.10; all dependencies already in `pyproject.toml`
- `random_state=42` / `SEED=42` on all stochastic calls
- `N_CLUSTERS = 16` — never hardcode 16 inline; use the constant
- Notebook runnable via `uv run jupyter nbconvert --to notebook --execute
  notebooks/11_improved_clustering.ipynb --output-dir notebooks
  --ExecutePreprocessor.timeout=1800` (30 min — DEC × 2 is slow on CPU)
- No modification to existing notebooks or result files
- Embedding files cached with skip-if-exists: check
  `Path(cache_path).exists()` before encoding
- `run_and_save()` signature: `(name: str, cluster_labels: np.ndarray,
  emb_original: np.ndarray) -> None` — identical to notebook 02
- UMAP default params for experiments A and C: `n_neighbors=15,
  min_dist=0.1, n_components=50, metric="cosine", random_state=42`
- Silhouette subsampling: `SILHOUETTE_SAMPLE_SIZE = 2000`
